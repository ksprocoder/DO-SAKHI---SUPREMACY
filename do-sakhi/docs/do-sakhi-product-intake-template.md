# Do Sakhi — Product Intake Template

Use this template for every new product before it is uploaded to the platform.  
Complete all fields. Incomplete entries will be saved as **Draft** and must be finished before going Active.

---

## 1. General Information

| Field | Value |
|---|---|
| **Product Name** | e.g. *Ivory Leaf Print Summer Suit Set* |
| **Product Type** | Suit Set / Kurti / Co-ord Set / Saree / Lehenga / Gown / Jacket Set / Dupatta / Accessory / Other |
| **Status at Upload** | Draft (default) / Active |
| **Collection / Category** | e.g. *New Arrivals*, *The Summer Edit*, *Festive Grace* |

---

## 2. Pricing & Inventory

| Field | Value |
|---|---|
| **Selling Price (INR)** | e.g. ₹3,200 |
| **Available Sizes** | XS / S / M / L / XL / XXL / Free Size |
| **Stock per Size** | e.g. S: 3, M: 4, L: 2 |
| **Custom Fit Available?** | Yes / No |
| **Is Ready to Ship?** | Yes / No |
| **Lead Time (if made-to-order)** | e.g. 7–14 days |

---

## 3. Product Details & Specifications

| Field | Value |
|---|---|
| **Colour** | e.g. Ivory, Sage Green, Dusty Rose |
| **Fabric** | e.g. Pure Muslin, 80% Cotton 20% Linen |
| **Work / Print / Embroidery** | e.g. Block print, Chikankari, Sequin border |
| **Occasion** | e.g. Everyday Luxury, Festive Grace, Resort Wear |
| **Fit / Silhouette** | e.g. Relaxed A-Line, Straight Fit, Flared |
| **Kurti / Top Length** | e.g. Knee-length, Hip-length (if applicable) |
| **Bottom Type** | Palazzo / Straight Pant / Skirt / Salwar / N/A |
| **Dupatta Included?** | Yes / No |
| **Care Instructions** | e.g. Dry clean only / Gentle hand wash in cold water |

---

## 4. Premium Copy

### Short Description (1–2 sentences)
> _e.g. A soft ivory suit set with delicate leaf block print, crafted in pure Rajasthani muslin. Designed for quiet luxury in warm weather._

### Premium Product Story (Full editorial paragraph — Do Sakhi tone)
> _Should include: emotional opening line, fabric feel, styling suggestion, occasion fit note, and care reference. 80–150 words._

---

## 5. SEO Information

| Field | Value |
|---|---|
| **SEO Title** | e.g. *Ivory Leaf Print Suit Set — Do Sakhi Quiet Luxury Boutique* |
| **SEO Description** | 140–160 characters. e.g. *Shop the Ivory Leaf Print Summer Suit Set from Do Sakhi — pure muslin, block print, relaxed A-line silhouette. Custom fit available.* |

## 6. Required Photography Checklist

Refer to the **[Image Naming Guide](./do-sakhi-image-naming-guide.md)** for file naming.

| Shot | Status | File Name |
|---|---|---|
| Front view | ☐ Ready | `product-slug_front.jpg` |
| Side view | ☐ Ready | `product-slug_side.jpg` |
| Back view | ☐ Ready | `product-slug_back.jpg` |
| Fabric / print close-up | ☐ Ready | `product-slug_fabric.jpg` |
| Detail / embroidery close-up | ☐ Ready | `product-slug_detail.jpg` |
| Dupatta / drape view | ☐ Ready / N/A | `product-slug_drape.jpg` |
| Lifestyle / model image | ☐ Ready / Optional | `product-slug_lifestyle.jpg` |

> **Rule:** Always upload the `_front` image first. It is used as the primary thumbnail in the shop grid, admin table, cart, and homepage curation sections.

## 8. Upload Checklist

Before uploading, tick all boxes:

- [ ] Product name confirmed
- [ ] Product type confirmed
- [ ] All sizes and stock quantities filled in
- [ ] Price confirmed
- [ ] Short description written
- [ ] Premium product story written
- [ ] SEO title written
- [ ] SEO description written
- [ ] All required images named correctly
- [ ] Front image ready to upload first
- [ ] Care instructions written
- [ ] Status set to Draft (default for new products)

---

> **Do NOT upload a product without completing Sections 1–5 and the front image.**  
> Products without premium copy or photography degrade the boutique experience.
