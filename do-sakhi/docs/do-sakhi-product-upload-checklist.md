# Do Sakhi — Product Upload Checklist

Use this checklist every time a new product is being prepared for upload.  
Do not upload a product until every item below is confirmed.

---

## Before You Start

- [ ] You have the physical sample or confirmed production piece in hand (or approved photos)
- [ ] The product has been photographed according to the [Image Naming Guide](./do-sakhi-image-naming-guide.md)
- [ ] The product intake form has been filled in fully

---

## Section A — Product Information Ready

- [ ] Product name is finalized (no typos, no placeholder names)
- [ ] Product type is selected (Suit Set / Kurti / Co-ord Set / Saree / Lehenga / etc.)
- [ ] Colour is confirmed (exact shade name, not just "blue")
- [ ] Fabric composition is confirmed (e.g. "70% Cotton, 30% Viscose")
- [ ] Work / print / embroidery details are written
- [ ] Occasion is assigned
- [ ] Fit / silhouette is described
- [ ] Kurti / top length noted (if applicable)
- [ ] Bottom type noted (if applicable)
- [ ] Dupatta included: Yes / No confirmed
- [ ] Care instructions written

---

## Section B — Sizing & Stock Ready

- [ ] All available sizes listed (XS / S / M / L / XL / XXL / Free Size)
- [ ] Stock count per size is confirmed and accurate
- [ ] Custom fit availability confirmed (Yes / No)
- [ ] Lead time written (if made-to-order)

---

## Section C — Pricing Confirmed

- [ ] Selling price confirmed in INR
- [ ] Price approved by boutique owner before upload

---

## Section D — Premium Copy Ready

- [ ] Short description written (1–2 sentences)
- [ ] Full premium product story written (80–150 words, Do Sakhi tone)
- [ ] Story has been reviewed for spelling and editorial quality

---

## Section E — SEO Ready

- [ ] SEO title written (includes product name + "Do Sakhi")
- [ ] SEO description written (140–160 characters, includes key fabric and occasion)

---

## Section F — Images Ready

- [ ] `product-slug_front.jpg` — ready and correctly named
- [ ] `product-slug_side.jpg` — ready or documented as missing
- [ ] `product-slug_back.jpg` — ready or documented as missing
- [ ] `product-slug_fabric.jpg` — ready or documented as missing
- [ ] `product-slug_detail.jpg` — ready or documented as missing
- [ ] `product-slug_drape.jpg` — ready / N/A if no dupatta
- [ ] `product-slug_lifestyle.jpg` — ready / optional
- [ ] All images are compressed under 500 KB
- [ ] All images have 4:5 aspect ratio
- [ ] Front image will be uploaded first

---

## Section G — Admin Upload Steps

1. [ ] Open `/admin/products/new`
2. [ ] Fill in all required fields from Sections A–E
3. [ ] Upload images — front image first
4. [ ] Set status to **Draft**
5. [ ] Save the product
6. [ ] Confirm the product appears in `/admin/products`
7. [ ] Preview the product at `/product/[slug]` to check all details
8. [ ] Check the product thumbnail appears in the admin table
9. [ ] Set status to **Active** only when all copy, images, and stock are confirmed

---

## Section H — Quality Check (Before Going Active)

- [ ] Product page loads without errors
- [ ] All images load without broken icons
- [ ] Product title, price, description display correctly
- [ ] Size options show correctly
- [ ] "Add to Cart" button works
- [ ] Product appears in Shop grid
- [ ] Product thumbnail shows in admin products table
- [ ] No console errors in browser dev tools

---

## Post-Upload Notes

> **Status reminder:** Always start at **Draft**. Move to **Active** only after the quality check above is passed.

> **Image reminder:** If some images are missing at upload time, document them in the intake form with a target shoot date.

> **Stock reminder:** Update stock counts after each sale in the admin panel.

---

*This checklist must be completed for every product before it is made Active on the Do Sakhi platform.*
